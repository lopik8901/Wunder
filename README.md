# Wunder Connectome AutoML

Phase 1 integration for running vanilla MLEvolve against the WunderNN Connectome evaluator with a Codex CLI LLM backend.

See `PHASE1_IMPLEMENTATION.md` for the verified two-candidate smoke trajectory and `CONNECTOME_AUTOML_PLAN.md` for the research plan.

Competition datasets, authenticated assets, model binaries, virtual environments, API credentials, and generated experiment workspaces are intentionally excluded.

Competition engineering on the migrated AMD GPU machine is documented in
[`competition_engineering/README.md`](competition_engineering/README.md).
See its plan, experiment ledger, environment records, and runbook before starting
new experiments. The historical eight-sequence search is not the training default.
